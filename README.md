# HTB Academy - Windows Fundamentals
## Section 13: Windows Security

### 📝 Module Notes
- Security Identifier (SID): A unique string value generated by Windows for each user account and group to manage access rights.
  - Structure: `S-1-5-21-(Domain/Machine SID)-(RID)`
  - Common RIDs: `500` (Administrator), `501` (Guest), `100x` (Custom Users).
- Windows Registry: A hierarchical database containing low-level settings for the OS and applications.
  - Hive Files Location: `C:\Windows\System32\Config\`
  - Persistence / Startup Keys: Located in `HKLM` and `HKCU` under `\Software\Microsoft\Windows\CurrentVersion\Run`.

### 💻 here you have  Useful Commands 
#### Query User SID
- PowerShell:
Get-LocalUser -Name "bob.smith" | Select-Object Name, SID
##### Alternative using  :Command Prompt (CMD):
cmd
wmic useraccount where name='bob.smith' get name,sid  (Here I used WQL)
#### Inspect Startup Registry Keys (Run Keys)
- CMD:
- cmd
reg query HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
reg query HKEY_LOCAL_MACHINE\Software\Microsoft\Windows\CurrentVersion\Run
